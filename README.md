# Number Guessing Game

A simple interactive number guessing game developed in Python. The objective is to guess a randomly generated number within a limited number of attempts. The game offers three difficulty levels, each providing a different number of chances to find the correct answer.

# Difficulty Levels

- Easy: 10 attempts
- Medium: 5 attempts
- Hard: 3 attempts

# Features

- Random number generation.
- Multiple difficulty settings.
- Limited attempts based on selected difficulty.
- Hints indicating whether your guess is too high or too low.
- Input validation to handle incorrect entries.
- Win and lose conditions.
- Interactive gameplay through the terminal.

# Technologies Used

- Python 3
- Random module
- Conditional statements
- While loops
- User input handling

# How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Open the project folder.
4. Run the Python file:

python main.py
